# Commesse LMT65
Generatore di commesse (tagli, lavorazioni, distinta, job XML per FSTLine) per il centro di lavoro FOM LMT 65.
Serie AluK: C75S, C82S-CS (finestre) e D67 / D77 = IWG 67ID / IWG 77ID (porte); Cortizo COR 80 Evolution (COR80, finestre e portefinestre, ala 39/21, ante a scomparsa / semivista / in vista / semivista ridotta).

- Programma pronto all'uso: `dist/Commesse_LMT65.html` (apri nel browser; `dist/dati_serie.js` accanto è facoltativo).
- Documentazione completa e stato del progetto: `docs/DOSSIER_PROGETTO_LMT65.md`.
- Istruzioni per lo sviluppo con Claude Code: `CLAUDE.md`.
